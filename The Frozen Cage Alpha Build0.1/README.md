# The Frozen Cage

Данный репозиторий содержит исходный код и собранный билд 3D компьютерной игры «The Frozen Cage» в жанре детективный хоррор.

Проект состоит из архива с запускаемым exe-файлом.

### Стек технологий:
- Движок: Unity 6000.3.7f1 (Universal Render Pipeline)
- Язык программирования: C#
- Архитектура: событийно-ориентированная, компонентная система сохранений
- Дополнительно: NavMesh, Newtonsoft.Json, DOTween

### Инструкция по запуску:
1. Распакуйте архив с игрой в удобное место.
2. Запустите файл `TheFrozenCage.exe`

**Важно:**
При изменении настроек их необходио сохранять. Если изменить настойки и не сохранить, настройки не изменятся и так как они стоят по умолчанию кнопка поставить по умолчанию ничего не сделает. При нажатии поставить по умолчанию нет визуального эффекта выставления настроек, изменения будут видны, когда при кастамных настройках нажать кнопку по умолчанию, сохранить и перезайти в настройки они будут по умолчанию.

Что бы пройти первую локацию нужно подобрать бейдж на земле. Поговорить с патрульным и после этого можно будет подойти к машине и взять блокнот. Далее можно будет подойти к нашей машине и отправится на вторую локацию.
